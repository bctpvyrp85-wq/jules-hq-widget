# Security policy

The Scriptable widget downloads JSON from a configurable public HTTPS URL. It does not need passwords or authentication tokens.

- Never paste API keys, session tokens, private server addresses, or personal data into a public widget script or JSON feed.
- If you discover a vulnerability, **do not publish exploit details or secrets in a public issue**. Use GitHub's private vulnerability reporting feature if enabled for this repository, or ask the maintainer for a private contact channel.
- The example snapshot is not a live control interface and must not be treated as a secure source of operational truth.

Security fixes are welcome via appropriately coordinated pull requests.
